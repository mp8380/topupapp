# YourName Topup App

A gaming-currency top-up web app with:

- Kazuki-inspired landing page style with carousel hero.
- User auth (register/login).
- User dashboard to place manual top-up orders.
- Admin dashboard to review all orders and update status.
- Synced order status between admin and user dashboards.

## Run locally

```bash
npm install
npm start
```

Open http://localhost:3000

## Default admin login

- Email: `admin@yourname.com`
- Password: `admin123`

## Order fields captured

- Date & time
- Customer name
- Mobile number
- Game
- Currency type
- Amount
- Player ID
- Notes
- Status
